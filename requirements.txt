# Runtime dependency.
#
# Pinned to 1.28.1 deliberately, not to the newest release. The 2.x line exists
# (2.2.0 at time of writing) and the FastMCP tool-registration API is exactly
# the kind of thing that moves across a major version. 1.28.1 is the version
# this server was developed and verified against, including the end-to-end
# smoke test. Bump it in its own commit, with the smoke test as the evidence.
mcp==1.28.1

# Nothing else is required at runtime, on purpose.
#
# `server/scope.py` and `server/verify.py` import only the standard library
# (re, json, ast, typing) plus the vendored parser. That is what lets the whole
# test suite and the eval gate run offline with no install step. The mcp
# dependency is imported lazily inside build_server() so importing the tool
# function never requires it.
#
# Dev/test tooling lives in requirements-dev.txt and is not needed to run the
# server.
