netverify / console
MCP — connecting

Check what an MCP server really does, before a model depends on it.

netverify verifies network-device command output before a model reads it. This console runs the real server two ways — in-process and over stdio — so you can exercise its tools, read the actual protocol frames, and see the telemetry each call produced.

Console

Protocol transcript

Spawns python -m server, speaks newline-delimited JSON-RPC to its stdin, and shows every frame that came back. Stdout is the protocol channel, so a stray print or a missing answer shows up here by name.

Telemetry

OpenTelemetry providers are installed before the server imports, so the spans and counters below are what the calls recorded — not what the code claims.

Read-only by design

The server holds no credentials, opens no sockets, and treats device output as hostile — masked, never echoed, counted by kind.
